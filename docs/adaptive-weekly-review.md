# Adaptive Weekly Training Review

Live Adaptive generation requires the server setting `SETRA_ADAPTIVE_GENERATION_ENABLED=true`. Keep it unset or false for the initial beta. This setting also covers Ask Setra, recommendations and new plan adjustment proposals. Saved reviews remain available to eligible users.

The review is generated by a normal authenticated API request. It does not require a Vercel schedule, so it works on Vercel Hobby.

## Required configuration

1. Apply the repository's Supabase migrations in order, including `20261124000600_add_adaptive_weekly_reviews.sql` and `20261127000600_protect_weekly_review_generation.sql`.
2. Add these server environment variables in Vercel and locally:

```text
AI_PROVIDER=openai
OPENAI_API_KEY=your_server_key
OPENAI_WEEKLY_REVIEW_MODEL=gpt-6-luna
```

`OPENAI_API_KEY` must never use a `NEXT_PUBLIC_` prefix.

## Generation

On the first app open after a configured training week finishes, an entitled Adaptive account asks the server for the latest review. If no stored review exists and that week has planned or completed training, the server builds a compact context and generates it once. The same endpoint powers the explicit Generate action. New generations only target the latest closed configured week, and each week allows up to four attempts, including failures and updates. Older saved reviews remain readable.

The database stores a unique row per user and week start. An atomic database claim prevents simultaneous app opens or retries from creating duplicate model calls. If training data later changes, the context hash changes and the UI offers an explicit update.

## Data sent to the provider

Only a compact JSON context is sent:

- configured week start, end and timezone
- planned, completed, skipped and rescheduled counts
- adherence percentage
- completed session count and recorded duration
- strength sets and numeric load volume
- endurance distance and activity mix
- previous-week totals and recent four-week averages
- session RPE, feel and a maximum of 300 characters from each relevant athlete comment
- active goals and reliable measured progress
- active program name, focus and week number
- verified all-time strength and standard-distance endurance PBs achieved during the reviewed week
- explicit data gaps

Raw database rows, account details, friends, private notes and unrelated history are not sent.
